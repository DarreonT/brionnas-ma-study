BRIONNA'S MA STUDY — iPHONE WEBSITE (VERSION 14)

WHY THE OLD FILE WAS BLANK ON IPHONE
On iPhone, downloaded HTML files often open in the Files/ChatGPT preview, which may not run JavaScript. This app needs JavaScript for all screens.

HOW TO OPEN THE ACTUAL APP ON IPHONE
1. On a COMPUTER, go to https://app.netlify.com/drop
2. Upload the FULL ZIP file Brionnas_MA_Study_iPhone_Website_V14.zip (or its extracted folder), not just index.html.
3. Wait for Netlify to give you an HTTPS link ending in netlify.app.
4. Open THAT LINK in Safari on your iPhone, NOT the downloaded HTML attachment.
5. Optional: Safari Share > Add to Home Screen to launch from an icon.

NOTE: Netlify's default site URL is public. The embedded photo is Brionna's original image and will be accessible to anyone with the site URL. Consider privacy before publishing.

Progress from a local downloaded file is NOT automatically transferred to the online website. The new site saves progress in the iPhone browser. Use the same URL each time.
